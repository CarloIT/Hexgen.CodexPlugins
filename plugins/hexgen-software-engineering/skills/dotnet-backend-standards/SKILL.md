# .NET 后端编程规范

1. 根据当前任务及相关项目文件确认 .NET 后端范围；仓库内存在 `.sln`、`.slnx`、`.csproj` 本身不足以让本 Skill 适用于前端工作。混合任务只对后端部分应用。
2. 先读[规范正文](references/dotnet-backend-standards.md)的 §1「总则」。涉及代码编写、修改或审查时，再读 §2–4「命名、组织、注释」、§6「异常与判空」及 §16「格式与控制流」；§1 的授权和范围约束适用于所有任务。
3. 按本次工作加载相关专题，不默认通读全部正文；被引用的规则若影响当前决策，再补读对应章节：
   - 异步、取消与并发：§5；资源释放、耗时与性能：§11。
   - 类型拆分和成员分组：§7–8；Controller：§9；DI 生命周期：§10。
   - 安全相关改动：§12；应用启动、配置与 Hexgen 底座装配：§13。
   - 变更验证或测试任务：§14；公共 API、目标框架、发布或混淆：§15。
4. 执行适用规则；用户明确指令和项目显式约定优先于 Skill 默认值。不要仅为满足本 Skill 扩大修改范围或重复请求已经获得的授权。Hexgen 默认体系、依赖边界及配置变更规则以 §1 为准。
